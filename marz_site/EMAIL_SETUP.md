# Enquiry email flow

The form offers Gmail and Outlook buttons. Each opens a browser draft addressed to poddapsychotherapy@gmail.com with the enquiry details filled in. The visitor presses Send in their email account. The form retains their details.

No email integration, credentials or server endpoint is required. The visitor may need to sign in to their chosen provider. The website cannot confirm delivery.

Validate with npm test, npm run typecheck and npm run build.
